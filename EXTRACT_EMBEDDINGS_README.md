# Embedding Extraction Utility

This utility extracts embeddings (hidden states) from Language Model outputs, specifically:
1. The embedding of the **last token of the input prompt**
2. The embeddings of **each token in the LLM response**
3. From a **specified layer** (or multiple layers)

## Features

- Extract embeddings from any specified layer: `all`, `last`, `mid`, or a specific layer number
- Support for both CUDA and CPU inference
- Output in JSON format for easy processing
- Standalone single file - easy to use and integrate
- Compatible with HuggingFace Transformers models

## Installation

Ensure you have the required dependencies:

```bash
pip install torch transformers
```

## Usage

### Basic Usage

```bash
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "What is the capital of France?" \
    --layer mid \
    --max_new_tokens 50
```

### Save to File

```bash
python extract_embeddings.py \
    --model_path meta-llama/Llama-2-7b-chat-hf \
    --prompt "What is machine learning?" \
    --layer mid \
    --max_new_tokens 30 \
    --output_file embeddings.json
```

### Extract from Multiple Layers

```bash
# Extract from all layers
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "Explain quantum computing" \
    --layer all \
    --output_file embeddings_all_layers.json

# Extract from last layer only
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "Explain quantum computing" \
    --layer last

# Extract from a specific layer (e.g., layer 16)
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "Explain quantum computing" \
    --layer 16
```

### Specify Device

```bash
# Force CPU usage
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "What is AI?" \
    --device cpu

# Use CUDA (default if available)
python extract_embeddings.py \
    --model_path /path/to/model \
    --prompt "What is AI?" \
    --device cuda
```

## Arguments

| Argument | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `--model_path` | str | Yes | - | Path to the pretrained model (local path or HuggingFace model ID) |
| `--prompt` | str | Yes | - | Input prompt text |
| `--layer` | str | No | `mid` | Layer(s) to extract: `all`, `last`, `mid`, or a specific number (e.g., `16`) |
| `--max_new_tokens` | int | No | `50` | Maximum number of tokens to generate |
| `--output_file` | str | No | None | Path to save embeddings as JSON. If not provided, prints summary only |
| `--device` | str | No | Auto | Device to use: `cuda` or `cpu`. Auto-detects if not specified |

## Output Format

When using `--output_file`, the script generates a JSON file with the following structure:

```json
{
  "input_prompt": "What is the capital of France?",
  "input_tokens": [1, 1724, 338, 278, 7483, 310, 3444, 29973],
  "input_text_tokens": ["<s>", "▁What", "▁is", "▁the", "▁capital", "▁of", "▁France", "?"],
  "last_input_token_id": 29973,
  "last_input_token_text": "?",
  "last_input_token_embedding": {
    "layer_16": [0.123, -0.456, 0.789, ...]
  },
  "generated_text": "The capital of France is Paris.",
  "generated_tokens": [450, 7483, 310, 3444, 338, 3681, 29889],
  "generated_text_tokens": ["▁The", "▁capital", "▁of", "▁France", "▁is", "▁Paris", "."],
  "generated_tokens_embeddings": [
    {
      "token_id": 450,
      "token_text": "▁The",
      "embeddings": {
        "layer_16": [0.234, -0.567, 0.890, ...]
      }
    },
    ...
  ],
  "layers": [16],
  "layer_spec": "mid",
  "num_layers": 33,
  "hidden_size": 4096
}
```

## Output Fields

### Top-level fields:
- `input_prompt`: The original input prompt text
- `input_tokens`: List of token IDs for the input
- `input_text_tokens`: List of tokens as text (with special characters showing tokenization)
- `last_input_token_id`: Token ID of the last input token
- `last_input_token_text`: Text of the last input token
- `last_input_token_embedding`: Dictionary with embeddings per layer for the last input token
- `generated_text`: The generated response text
- `generated_tokens`: List of token IDs generated by the model
- `generated_text_tokens`: List of generated tokens as text
- `generated_tokens_embeddings`: List of embeddings for each generated token
- `layers`: List of layer indices that were extracted
- `layer_spec`: The layer specification used
- `num_layers`: Total number of layers in the model
- `hidden_size`: Dimension of the hidden states/embeddings

### For each generated token:
- `token_id`: The token's ID
- `token_text`: The token as text
- `embeddings`: Dictionary with embedding vector(s) per layer

## Integration with Existing Code

This utility is designed as a standalone tool but follows similar patterns to the existing `utils/llm.py` in the repository. The key differences:

1. **Simplified Interface**: Single function call to extract embeddings
2. **Standalone**: No dependencies on other repository modules
3. **Clear Output**: Structured JSON format for easy post-processing
4. **Focused Purpose**: Specifically extracts last input token and all response token embeddings

## Technical Details

### Embedding Extraction Process

1. **Input Processing**: 
   - Tokenizes the input prompt
   - Identifies the last token position

2. **Generation**:
   - Generates response tokens using greedy decoding
   - Captures hidden states at each generation step

3. **Embedding Extraction**:
   - For the last input token: Extracts hidden state from the initial forward pass
   - For each generated token: Extracts hidden state from its generation step
   - Supports extraction from single or multiple layers

4. **Output**:
   - Converts tensors to Python lists for JSON serialization
   - Converts float16 to float32 for compatibility

### Memory Considerations

- Models are loaded in float16 on CUDA to save memory
- For very long sequences, consider processing in smaller batches
- Use specific layer extraction (not `all`) for large models to reduce memory usage

## Compatibility

- **Models**: Any HuggingFace Transformers causal language model
- **Python**: 3.7+
- **PyTorch**: 1.9+
- **Transformers**: 4.20+

## Troubleshooting

### Out of Memory Error
- Try using `--device cpu` for smaller models
- Reduce `--max_new_tokens`
- Use specific layer instead of `--layer all`

### Model Not Found
- Ensure the model path is correct
- For HuggingFace models, ensure you have internet connection
- Check if you need authentication for gated models

### Slow Generation
- This is expected for large models on CPU
- Consider using a smaller model for testing
- Use GPU if available
